Struktur database belum diperbarui

Database tersambung, tetapi ada tabel/kolom baru yang belum dibuat.

  1. Jalankan python manage.py migrate, atau
  2. restart server (runserver), karena migrasi berjalan otomatis saat server start.
{% elif jenis == 'database' %}

Database "{{ db_name }}" tidak ditemukan

  1. Buka phpMyAdmin / HeidiSQL di Laragon.
  2. Buat database {{ db_name }}, lalu import file db_dinezy.sql.
  3. Atau ubah DINEZY_DB_NAME di file .env.
{% elif jenis == 'akses' %}

Login ke MySQL ditolak

Username / password MySQL tidak cocok. Sesuaikan DINEZY_DB_USER dan DINEZY_DB_PASSWORD di file .env.

{% elif jenis == 'koneksi' %}

Server database tidak dapat dihubungi

  1. Pastikan MySQL sudah Start di Laragon (ikon MySQL berwarna hijau).
  2. Cek host & port: {{ db_host }}:{{ db_port }}. Jika MySQL Laragon memakai port lain, ubah DINEZY_DB_PORT di .env.
  3. Setelah MySQL menyala, cukup muat ulang halaman ini. Sistem tersambung ulang otomatis.
{% else %}

Jalankan python manage.py cek_database untuk diagnosa lengkap.
